# 桌面日程 · Windows 下载

半透明桌面日历，集中查看每天的日程、待办、便签和倒计时。

桌面日历和完整主界面可以同时显示。打开待办、便签、设置等页面时，日历仍然保留；每个窗口的最小化和关闭按钮只隐藏自身。

## 快速开始

1. 下载并运行 `Desktop-Daybook-Setup.exe`，按安装向导完成安装。
2. 启动“桌面日程”，在桌面日历上双击日期，填写事项并保存。
3. 需要到时提醒时，勾选“到时提醒我”，再设置时间和提前提醒。
4. 右上角“…”可调整透明度，或打开待办、便签和设置。

| 常用操作 | 方法 |
| --- | --- |
| 新增日程 | 双击日期格，或按 `Ctrl+Alt+N` |
| 编辑日程 | 单击日程条 |
| 删除日程 | 单击日程条 → 底部“删除待办” → 确认 |
| 打开完整主界面，保留日历 | `Ctrl+Alt+M`，或托盘“打开主界面” |
| 再次显示日历 | 托盘“显示桌面日程”，或双击托盘图标 |
| 隐藏当前窗口到托盘 | 点击该窗口的最小化或关闭，另一个窗口不受影响 |
| 导出／恢复数据 | 完整主界面 → 设置 → 数据 |

保存或取消编辑后，日历继续停留；点击最小化或关闭时才隐藏。需要日历始终盖在其他窗口上方时，在“…”中开启“始终置顶”。
